# LABO 03 : CODEBREAKER

## But
Deviner un code secret

## 3 modes de jeu
1) partie classique
2) Partie personnalisée
3) partie à 2 joueurs

## Construction de l'exécutable
mingw32-make all

## Lancer le programme
mingw32-make run

## Nettoyer les objets et l'exécutable
mingw32-make clean

## Précision
Si la longueur du code = n , saisie utilisateur acceptée à n - 1 :  le digit non saisi = 0
